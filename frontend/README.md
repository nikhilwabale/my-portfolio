# Nikhil Wabale Portfolio V11

Frontend-only Next.js portfolio with Web2-inspired professional layout, cinematic preloader, polished hero, dark/light theme, locked search modal, Framer Motion animations, SEO metadata, sitemap and robots.

## Run

```bash
npm install
npm run dev
```

## Notes
- Default theme is dark. Use the header toggle for light mode.
- Search modal locks page scrolling until closed.
- Scroll progress and circular scroll-to-top button are included.
